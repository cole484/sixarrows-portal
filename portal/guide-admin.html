Admin Guide

Everything you need to manage the Six Arrows client portal — from adding clients to syncing budgets.

Logging In

The admin panel lives at /portal/admin.html. When you visit the page, you'll see a password prompt.

1Go to your portal URL + /portal/admin.html
Example: https://yoursite.netlify.app/portal/admin.html
2Enter the admin password
Type the admin password and click Sign In. The session persists until you close the browser tab.
Tip: Bookmark the admin page for quick access. Your login session is stored in the browser tab — opening a new tab requires logging in again.

Navigation Overview

Once logged in, you'll see a sidebar with your client list and a set of view tabs across the top for the selected client. Here's the layout:

  • Left sidebar — Lists all clients. Click a client name to select them.
  • Top tabs — Switch between views for the selected client:
    • Tracker — SAB Blueprint progress / remodel milestones
    • Updates — Post and manage project updates
    • Timeline — Milestones and build schedule
    • Budget — Categories, spending, and change orders
    • Project — Core client and project settings
    • Decisions — Outstanding client decisions
    • Selections — Wave selections progress
    • Documents — Uploaded files and links
    • Photos — Build photo galleries
  • + Add Client — Button at the bottom of the sidebar to create a new client

Adding a New Client

To create a new client and give them access to the portal:

1Click "+ Add Client" in the sidebar
This opens the new client form.
2Fill in the required fields
FieldDescription
Client NameThe homeowner's name (e.g., "James & Dana Johnson")
EmailTheir login email address
PasswordTheir portal login password
Project NameDisplay name for the project (e.g., "The Johnson Residence")
LocationCity/neighborhood (e.g., "Franklin, TN")
Status TypeChoose sab (preconstruction) or construction
Team LeadPrimary contact name for the project
3Click "Create Client"
The system creates the client record and 8 default budget categories. The client can immediately log in with their email and password.
Tip: After creating the client, go to the Project tab to fill in additional details like Notion IDs, budget sheet URL, photo folders, and selections client key.

Editing Client Info

To update a client's details:

1Select the client from the sidebar
Click their name to load their project data.
2Go to the "Project" tab
This shows all editable fields for the client and project.
3Edit the fields you need to change
You can update any field: name, email, password, project details, team info, integration IDs, and more.
4Click "Save Changes"
Changes take effect immediately — the client will see updated info on their next page load.

Removing a Client

To remove a client from the portal:

1Select the client from the sidebar
Click their name to load their data.
2Go to the "Project" tab
Scroll to the bottom of the page.
3Click "Delete Client"
You'll be asked to confirm. This permanently removes the client and all their associated data (budget categories, updates, milestones, decisions, documents).
Warning: Deleting a client is permanent and cannot be undone. All their data — budget, updates, milestones, decisions, and documents — will be permanently deleted.

Client Types & Phases

The portal supports two client types, each with a different experience:

TypeStatus TypePortal Experience
Preconstruction (SAB) sab Shows SAB Blueprint tracker with 3 phases (Design, Selections, Build-Ready). Dashboard shows progress cards, decisions, and selections. Budget syncs from Google Sheets.
Construction construction Shows build timeline from Notion, budget breakdown, photo galleries, milestone tracking. Dashboard shows construction progress percentage.

To switch a client from preconstruction to construction (e.g., when they break ground), update the Status Type field in the Project tab from sab to construction.

Tracker Overview

The Tracker view lets you manage a client's progress through the SAB Blueprint process or a remodel project. What you see depends on the project type:

  • New builds — Uses the pattern-based SAB Blueprint with 3 fixed phases and predefined steps
  • Remodels — Uses dynamic mode, pulling phases and steps from a Notion page

SAB Blueprint Steps

For new build clients, the SAB Blueprint has 3 phases:

  1. Phase 1: Design — Architectural plans, engineering, HOA review, permitting
  2. Phase 2: Selections — Material and fixture selections (Wave 1, 2, 3)
  3. Phase 3: Build-Ready — Final budget, pre-construction meeting, groundbreaking

Each phase contains multiple steps with checkbox items. To manage progress:

1Select the client and go to the Tracker tab
You'll see the phase tabs at the top and steps listed below.
2Check off completed items within each step
Click the circle next to each item to mark it complete. The step's progress bar updates automatically.
3Set the groundbreaking / demo start date (optional)
Use the date picker at the top of the tracker to set a target date. This displays as a countdown on the client's dashboard.
Tip: Clients can view all phases and steps (they're not locked out of future phases), but only the admin can check/uncheck items. The client's portal auto-scrolls to their current active phase.

Remodel / Dynamic Mode

For remodel clients, the tracker pulls its structure directly from a Notion page. The Notion page should be formatted as:

  • H2 headings = Phase names
  • H3 headings = Step names within each phase
  • To-do checkboxes = Individual items within each step

When you check/uncheck items in Notion, the portal syncs automatically on page load. You can also manage items directly in the admin panel.

Notion Sync

The tracker can sync with Notion for both new builds and remodels:

1Get the Notion page ID
Open the Notion page, copy the URL. The page ID is the long string of characters at the end (after the last dash). Example: https://notion.so/My-Page-abc123def456
2Paste into "Notion Tracker Page ID" in the Project tab
Save the project settings. The tracker will now sync from this Notion page.
Note: Notion is authoritative — when sync runs, it overwrites local tracker state. If you make changes in the admin panel, they may be overridden by the next Notion sync. For the most consistent experience, manage steps in Notion and let the portal sync.

Posting Manual Updates

Updates appear on the client's Updates page and are summarized on their command center.

1Go to the Updates tab for the client
You'll see existing updates and a form to create new ones.
2Fill in the update title and body
Write a clear, concise update. The title shows in the update list; the body shows when the client clicks to read more.
3Click "Post Update"
The update is immediately visible to the client on their portal.

AI-Generated Drafts

The system can automatically generate project updates using AI (powered by Claude). These run on a schedule:

  • Monday mornings — Weekly kickoff update summarizing the week ahead
  • Friday afternoons — Weekly wrap-up summarizing progress made
  • Midweek — Optional midweek check-in

AI drafts are not automatically published — they go into a pending queue for you to review, edit, and approve before the client sees them.

Approving & Editing Drafts

1Go to the Updates tab — look for "Pending Drafts"
Pending AI-generated drafts appear in a separate section at the top.
2Review the draft content
Read through the generated text. The AI uses project data (milestones, tracker progress, recent updates) to craft the message.
3Edit if needed, then Approve or Reject
  • Approve — Publishes the update to the client immediately
  • Reject — Discards the draft permanently
  • Edit — Modify the text before approving
Tip: Always review AI drafts before approving. The AI does a good job summarizing project data, but it's best to verify accuracy and add any personal touches.

Managing Budget Categories

The Budget tab shows all budget categories for a client, with totals, spent amounts, and status tracking.

Adding a Category

1Click "Add Category" in the Budget tab
Fill in the category name, total budget amount, and initial spent amount.
2Set the status
Choose: pending (not started), in_progress (actively tracking), or complete (finalized).
3Add sub-categories (optional)
Break down a category into line items. For example, "Flooring" might have sub-categories for "Hardwood", "Tile", and "Carpet" with individual amounts.

Editing & Deleting

Click on any existing category to edit its details, or use the delete button to remove it. Changes are saved immediately to the database.

Google Sheets Sync

Budget categories can be synced from a Google Sheet for more complex budget tracking.

1Set up the Google Sheet
In your budget spreadsheet, use Column Z to tag rows with their main category name. The sync function reads Column Z to group line items into categories.
2Add the Sheet URL to the client's Project tab
Paste the full Google Sheets URL into the "Budget Sheet URL" field and save.
3Sync runs automatically
For SAB clients, the budget syncs from the sheet every time the budget page loads. For remodel clients, it syncs when you open the admin Budget tab.
Note: When Google Sheets sync is active, sheet data is authoritative. Manual edits in the admin panel may be overwritten on the next sync. Make budget changes in the sheet, not the admin panel.

Change Orders

Change orders track budget modifications during the project. They appear as a separate section on the client's budget page.

1Go to the Budget tab and scroll to "Change Orders"
You'll see existing change orders and a form to add new ones.
2Add description and amount
Describe the change (e.g., "Upgraded kitchen countertops to quartz") and enter the dollar amount (positive for additions, negative for credits).

Managing Milestones

Milestones appear on the client's timeline and command center. They mark key project dates and events.

1Go to the Timeline tab
You'll see existing milestones and can add new ones.
2Add a milestone
Set the date, title (e.g., "Foundation Poured"), and optional note. Check "Done" if the milestone is already completed.
3Reorder milestones
Use the sort order field to control the display order. Lower numbers appear first.

Notion Timeline Sync

For construction-phase clients, the build timeline can sync from a Notion database:

1Create a Notion database with task entries
Each entry should have:
  • Task (or "Task Description") — The task name
  • Sequence # — Order number for sorting
  • Status — Completion status (checkbox or select)
2Copy the database ID and add it to the client
In the Project tab, paste the ID into "Notion Timeline DB ID" and save.

The timeline shows 3 completed tasks, the current active task, and 8 upcoming tasks — giving the client a focused view of where things stand.

Viewing Selections Progress

The Selections tab shows how far a client has progressed through their material and fixture selections, organized into three waves:

WaveCategories
Wave 1: StructureFireplace, Appliances, Exterior
Wave 2: ShellSpecialty Trim, Flooring, Tile
Wave 3: JewelryPlumbing, Lighting, Countertops, Hardware, Paint, Doors & Trim

Each category shows a completion percentage. Clients fill in their selections through the Selections App (selections-app.html), and the data syncs to Supabase.

Exporting Selections

To export a client's selections as a CSV spreadsheet:

1Go to the Selections tab
Click the "Export CSV" button.
2Download the file
The CSV includes a per-room breakdown of all selections with product names, colors, quantities, and notes.

Design Book

The Design Book is a visual reference that compiles a client's selections into a room-by-room lookbook. It's automatically generated from the client's selections data.

To access it: the client can reach it from their command center via the "View Design Book" link on the selections card. The URL is design-book.html.

The Design Book includes:

  • Cover page with project name and date
  • Room-by-room spreads for Kitchen, Bathrooms, Living areas, and more
  • Product images, names, colors, and specifications for each selection
  • Categories: flooring, tile, countertops, paint, doors/trim, plumbing, lighting, appliances, and more
Tip: Product images in the Design Book are loaded from the portal/assets/products/ directory. If a product image shows as blank, you may need to add the image file locally — many retailer websites block external image loading (hotlink protection).

Managing Decisions

Decisions are action items that require client input. They appear prominently on the client's command center with an alert badge.

1Go to the Project tab (Decisions section)
Scroll down to find the Decisions section, or look for a dedicated Decisions tab.
2Add a decision
Enter a title (e.g., "Confirm kitchen backsplash tile"), set status to pending, and add an optional note with details.
3Update status when resolved
Change status to resolved once the client makes their decision. The alert badge will clear from their dashboard.

Uploading Documents

Documents are organized by category and appear on the client's Documents page.

1Go to the Documents tab
You'll see existing documents grouped by category.
2Click "Add Document"
Fill in:
  • Name — Display name (e.g., "Floor Plan Rev 3")
  • Category — Plans, Budget, Selections, Photos, Contracts, or Other
  • URL — Link to the file (Google Drive, Dropbox, etc.)
  • Type — PDF, Sheet, Image, or Link
  • Note — Optional description
Tip: For Google Drive files, make sure the sharing settings are set to "Anyone with the link can view" so clients can access them.

Build Photos

Build photos are pulled from Google Drive folders and displayed in a gallery on the client's portal.

1Create Google Drive folders for each build phase
Example folders: "Foundation", "Framing", "Mechanical", "Drywall", "Finishes"
2Upload photos to the appropriate folders
Drop photos into the Google Drive folders as the build progresses.
3Add folder URLs in the Project tab
In the "Photo Folders" field, paste the Google Drive folder URLs. The system extracts folder IDs automatically.

Photos appear on the client's Photos page, grouped by folder (build phase). New photos are available as soon as they're uploaded to Drive — no manual sync needed.

Troubleshooting

Client can't log in

  • Verify their email and password in the admin Project tab
  • Make sure they're using the correct portal URL
  • Check that the client record exists in Supabase

Budget shows wrong numbers

  • If using Google Sheets sync, check that Column Z tags are correct in the sheet
  • Try reloading the admin Budget tab to trigger a fresh sync
  • For SAB clients, the budget dashboard card and budget page both pull from the sheet — verify the sheet data is accurate

Tracker not syncing from Notion

  • Verify the Notion Tracker Page ID is correct in the Project tab
  • Check that the Notion page is shared with the integration
  • For remodels, make sure the page uses H2 (phases), H3 (steps), and checkbox formatting

Photos not showing

  • Verify Google Drive folder URLs are correct in the Project tab
  • Make sure folders are shared (at least "Anyone with the link can view")
  • Check that folders contain image files (JPG, PNG, etc.)

Design Book shows "No selections"

  • Verify the Selections Client Key is set correctly in the Project tab
  • Check that the client has actually completed selections in the Selections App
  • Try viewing the selections data directly: open the Selections tab in admin to see completion status

Updates not appearing for client

  • AI-generated drafts must be approved before they're visible — check the pending drafts queue
  • Manually posted updates appear immediately — if missing, check the Updates tab for errors
