Program name

Six Arrows Construction Work Order Notifications.

Program description

Six Arrows Construction sends scheduling text messages to subcontractors we have hired. Messages contain a link to a work order showing the scope, dates and payment terms for that subcontractor's work, along with follow-up reminders when we have not received a response. This program is used only with subcontractors we have an existing working relationship with. We do not message consumers and we do not send marketing or promotional messages through this program.

How you joined this program

Subcontractors provide their mobile number to Six Arrows Construction when they begin working with us, and are told at that time that the number is used to send scheduling and work order messages.

Message frequency

Message frequency varies. Messages are sent only when there is an active work order for you, typically a few messages per project.

Cost

Message and data rates may apply. Six Arrows Construction does not charge you for these messages; any charges come from your own mobile carrier under your plan.

How to stop messages

You can cancel at any time. Reply STOP to any message from this number to opt out. After you send STOP, we will send one confirmation message and then no further messages will be sent to that number. To rejoin later, reply START to the same number.

How to get help

Reply HELP to any message from this number for assistance, or contact us using the details below.

Carrier liability

Mobile carriers are not liable for delayed or undelivered messages.

Supported carriers

Messages are delivered through major US mobile carriers. Delivery is subject to carrier availability and is not guaranteed.
