Scope and Completion Standard Library

How to use: Copy scope bullets and completion standard bullets directly into work orders for each trade. The cleanliness bullet below goes on every trade as the second-to-last item in every Completion Standard.
Standard Cleanliness Bullet - All Trades:
Site kept clean daily - all trash, debris, packaging, and waste materials removed from the work area before leaving each day. Tools and staged materials may remain on site but work areas must be left clean.

Sitework and Excavation

Scope

  • Clear and grub all vegetation within building footprint and disturbed area per plan
  • Strip and stockpile topsoil for later use or disposal as directed
  • Excavate for foundation per structural drawings and elevations
  • Excavate for all underground utilities as shown on site plan
  • Grade site to direct drainage away from building per grading plan
  • Install erosion control measures per plan and local requirements
  • Haul excess material off site or stockpile as directed by PM

Completion Standard

  • Excavation depth and dimensions match structural drawings within 2 inches
  • Bottom of excavation clean, level, and free of loose material
  • Erosion control measures installed and functional before any precipitation
  • All stockpiled material located per PM direction and not blocking site access
  • Site access maintained for all other trades throughout the work
  • Site kept clean daily - all trash, debris, packaging, and waste removed before leaving each day
  • PM notified and on-site inspection completed before foundation work begins

Concrete and Foundation

Scope

  • Form and pour all footings per structural drawings and engineer specifications
  • Install all reinforcement steel per structural drawings - size, spacing, and lap lengths as specified
  • Install anchor bolts per foundation plan - location, embedment, and projection as specified
  • Form and pour foundation walls or slab per structural drawings
  • Install all foundation drainage, waterproofing, and damp-proofing as specified
  • Install all sleeves and penetrations for utilities before pouring
  • Backfill against foundation after waterproofing is approved by PM

Completion Standard

  • All footings at correct depth per structural drawings - verified by PM before pour
  • All reinforcement placed, tied, and inspected before concrete placement
  • Anchor bolt locations match foundation plan within 1/4 inch - verified before pour
  • Foundation walls plumb within 1/4 inch per 10 feet
  • All penetrations and sleeves in correct locations per plan
  • Waterproofing applied per manufacturer instructions and inspected before backfill
  • Foundation inspection passed before framing begins
  • Site kept clean daily - all trash, debris, packaging, and waste removed before leaving each day
  • Concrete washout contained and not discharged on site

Framing

Scope

  • Frame all walls, floors, and roof per approved architectural and structural drawings
  • Install all headers per window and door schedule - sizes as specified by engineer
  • Frame all stair openings, mechanical chases, and specialty framing per plan
  • Install all engineered lumber and beams per structural drawings
  • Install roof framing and sheathing per plan
  • Install wall sheathing per plan
  • Set all window and door rough openings per schedule
  • Coordinate all mechanical penetrations with HVAC, plumbing, and electrical subs

Completion Standard

  • All walls plumb within 1/8 inch per 8 feet
  • All floors level within 3/16 inch over 10 feet
  • All headers correct size per schedule - no substitutions without engineer approval
  • All rough opening sizes match window and door schedule within 1/4 inch
  • All engineered lumber installed per manufacturer and engineer specifications
  • Roof sheathing nailed per nailing schedule
  • All blocking installed at bearing points, tub and shower surrounds, and grab bar locations
  • Framing inspection passed before any MEP rough-in begins
  • Site kept clean daily - all lumber scraps, cut-offs, packaging, and waste removed before leaving each day

Plumbing Rough-In

Scope

  • Install all drain, waste, and vent piping per plumbing plans and fixture schedule
  • Install all supply piping per plan and fixture rough-in dimensions
  • Install all fixture rough-in stubs at correct locations and heights per fixture rough-in sheets
  • Install water heater connections and venting as specified
  • Install exterior hose bib rough-in at all locations per plan
  • Install tub and shower valve rough-in at correct locations per plan
  • Install all cleanouts at required locations per code
  • Pressure test all supply lines before closing walls

Completion Standard

  • All drain and vent piping sloped correctly - minimum 1/4 inch per foot on drains
  • All supply stubs at correct height and location per fixture rough-in dimensions
  • All tub and shower valves at correct rough-in depth for specified fixtures
  • All vent penetrations through roof flashed and weathertight
  • Supply pressure test passed and documented - test results provided to PM
  • Plumbing rough-in inspection passed before insulation or drywall begins
  • Site kept clean daily - all pipe scraps, fittings, packaging, and waste removed before leaving each day
  • PM notified before any work is covered

Electrical Rough-In

Scope

  • Install all branch circuit wiring per approved electrical plans and panel schedule
  • Install all outlet and switch boxes at correct heights per plan
  • Install all recessed lighting rough-in boxes at locations per lighting layout
  • Install panel and service entrance per electrical plans
  • Install all dedicated circuits for appliances, HVAC, washer, dryer, and specified equipment
  • Install rough-in for all ceiling fans and exhaust fans per plan
  • Install smoke and CO detector rough-in at all code-required locations
  • Install low-voltage rough-in for structured wiring panel, data, cable, and speaker locations per plan
  • Coordinate with HVAC sub for equipment circuit locations before rough-in
  • All wiring stapled and secured per NEC

Completion Standard

  • All wiring installed, stapled, and secured per NEC throughout
  • All boxes set at correct heights - outlets at 16 inches, switches at 44 inches unless plan specifies otherwise
  • All boxes square and flush to stud face within 1/4 inch for drywall thickness
  • Panel roughed in with all circuits stubbed and labeled
  • All dedicated circuits installed and marked at panel
  • All recessed can locations confirmed against lighting plan - no deviations without PM approval
  • Smoke and CO detectors roughed in at all code-required locations
  • Low-voltage rough-in complete at all specified locations
  • Site kept clean daily - all wire scraps, packaging, and waste removed before leaving each day
  • Rough-in electrical inspection passed before notifying Six Arrows of completion
  • Inspection documentation provided to PM after passing

HVAC Rough-In

Scope

  • Install all ductwork per HVAC design drawings and equipment schedule
  • Install all equipment including air handlers, furnaces, and coils per plan
  • Install all supply and return registers at locations per plan
  • Install condensate drain lines at correct slope to approved drain locations
  • Coordinate all equipment electrical circuits with electrical sub before rough-in
  • Install all refrigerant line sets for split systems
  • Install all exhaust fans and ducting per plan

Completion Standard

  • All ductwork installed per design drawings - no field reroutes without PM approval
  • All supply and return register locations match plan within 2 inches
  • All equipment at correct location with adequate clearances per manufacturer requirements
  • Condensate drains pitched correctly and draining to approved locations
  • All exhaust fans vented to exterior - no exhaust fans terminating into attic
  • Dryer duct routed to exterior with correct duct type and maximum run length per code
  • HVAC rough-in inspection passed before insulation or drywall begins
  • Site kept clean daily - all duct scraps, packaging, and waste removed before leaving each day

Insulation

Scope

  • Furnish and install all insulation materials per plans and energy code requirements
  • Install specified R-values in exterior walls, ceilings, attic spaces, and rim joists
  • Install crawl space plastic sheeting and spray foam at foundation walls as specified
  • Spray foam all penetrations and gaps in exterior envelope
  • Maintain proper clearances at all recessed fixtures and mechanical equipment
  • Batt insulation in all interior wall and ceiling cavities as specified

Completion Standard

  • Crawl space plastic sheeting installed and spray foam on block wall all the way around
  • Spray foam around every window and every penetration where daylight is visible through exterior walls
  • Batt insulation in all interior wall and ceiling cavities - no gaps or voids
  • No spray foam in the interior of the home unless specifically specified
  • All recessed fixtures have correct clearance maintained
  • Insulation inspection passed before drywall begins
  • Site kept clean daily - all packaging, scraps, and waste removed before leaving each day

Drywall

Scope

  • Hang, tape, bed, and finish all drywall per plans
  • Install correct drywall type in all locations - moisture-resistant in bathrooms, fire-rated at garage
  • Install all corner bead, J-bead, and trim accessories
  • Finish to Level 4 throughout - Level 5 in any areas specified by PM
  • Install all access panels at locations specified by PM
  • Texture walls and ceilings as specified

Completion Standard

  • All drywall hung tight to framing - no waves, humps, or loose boards
  • All seams taped and finished - no visible seams or fastener dimples after final coat
  • All corners straight and true - no cracked or damaged corner bead
  • Level 4 finish throughout - smooth enough that paint will not telegraph tape seams
  • All electrical boxes, plumbing stubs, and HVAC supplies cut out cleanly
  • All access panels installed and operational
  • No nail pops, cracks, or areas requiring additional coats
  • Site kept clean daily - all drywall scraps, joint compound containers, and waste removed before leaving each day
  • PM walkthrough completed and approved before painter is scheduled

Painting

Scope

  • Prime all drywall surfaces with appropriate primer
  • Paint all walls, ceilings, and trim per approved paint schedule
  • Colors and sheens per room-by-room paint schedule approved by client
  • Paint all doors, door frames, and window trim per paint schedule
  • Apply two finish coats minimum over primer on all surfaces
  • Cut in all surfaces cleanly

Completion Standard

  • All surfaces have consistent sheen with no thin spots, roller marks, or brush lines visible in raking light
  • All colors match approved paint schedule - no substitutions without PM approval
  • All cut lines clean and straight - no paint on adjacent surfaces, hardware, or glass
  • All trim painted cleanly with no drips or brush marks
  • All switch plates and outlet covers removed during painting and reinstalled after
  • No paint on floors, hardware, glass, or fixtures
  • Touch-up list submitted to PM within 24 hours of completion
  • Site kept clean daily - all paint cans, rollers, drop cloths, and waste removed before leaving each day

Tile Installation

Scope

  • Install all tile per approved Tile Layout and Design Sheet on file
  • Layout per approved patterns, starting points, and grout joint sizes on sheet
  • Install all shower niches per locations and dimensions on design sheet
  • Install all Schluter and transition profiles per design sheet
  • Install bench and curb tile per design sheet
  • Grout all tile with specified grout type and color per design sheet
  • Apply grout sealer where specified

Completion Standard

  • All tile installed per the approved Tile Layout and Design Sheet - no deviations without PM approval
  • Grout joints consistent throughout - no variation greater than 1/16 inch
  • All niches tiled flush and level - no lippage
  • All Schluter and transition strips in approved color and profile
  • No lippage greater than 1/32 inch on rectified tile
  • Grout color matches approved specification
  • Grout fully cured before client walkthrough
  • Site kept clean daily - all tile scraps, packaging, and waste removed before leaving each day
  • Ready for grout sealer if required before notifying Six Arrows of completion

Flooring - LVP and Hardwood

Scope

  • Install all hard flooring per flooring schedule and layout plan
  • Install correct underlayment per manufacturer requirements
  • Acclimate flooring material per manufacturer specifications before installation
  • Install all transitions and T-moldings at doorways and flooring changes
  • Install base shoe or quarter round at all walls after flooring is complete

Completion Standard

  • All flooring installed per manufacturer specifications
  • All seams and end joints staggered per manufacturer minimum requirements
  • No squeaks or hollow spots
  • All transitions installed and secure at every flooring change
  • All cuts tight at walls - no gaps greater than 1/4 inch under base shoe
  • Base shoe nailed to base, not to flooring
  • Expansion gap maintained at all walls per manufacturer requirements
  • All flooring cleaned before PM walkthrough
  • Site kept clean daily - all scraps, packaging, and underlayment removed before leaving each day

Cabinets

Scope

  • Install all cabinets per approved cabinet layout drawings
  • Install all base, wall, and tall cabinets per plan
  • Install all cabinet hardware per hardware schedule
  • Install all fillers, scribe moldings, and trim pieces
  • Coordinate with countertop sub on template date

Completion Standard

  • All cabinets level, plumb, and square - no cabinet out of level by more than 1/16 inch
  • All doors and drawers aligned and operating smoothly
  • All hardware installed per hardware schedule
  • All fillers and scribes installed cleanly - no gaps greater than 1/16 inch at walls
  • Countertop template date coordinated with PM
  • Any damaged cabinets identified to PM before installation
  • Site kept clean daily - all packing materials, cardboard, and debris removed before leaving each day

Trim Carpentry

Scope

  • Install all base molding per plan and profile schedule
  • Install all door and window casing per plan and profile schedule
  • Install all crown molding at locations per plan
  • Install all built-ins, shelving, and specialty millwork as specified
  • Install all stair treads, risers, railings, and balusters per plan and code
  • Fill all nail holes and caulk all joints before painter arrives

Completion Standard

  • All base molding tight to floor and wall - no gaps greater than 1/16 inch
  • All casing joints tight at corners and returns - no open miters
  • All crown molding tight at ceiling and wall - consistent reveal throughout
  • All nail holes filled flush
  • All joints caulked cleanly
  • All stair railings secure - no movement at any post or baluster
  • Stair railing height and baluster spacing per code
  • PM walkthrough completed before painter is scheduled
  • Site kept clean daily - all cut-offs, sawdust, packaging, and waste removed before leaving each day
